# 🧮 Calculadora Simples em Python

Este foi um dos meus **primeiros projetos em Python**, feito quando comecei a explorar a linguagem e estudar lógica de programação.

## 💡 Sobre

A calculadora permite ao usuário escolher entre várias operações matemáticas básicas, como:

- Soma
- Subtração
- Multiplicação
- Divisão
- Potência
- Divisão inteira
- Porcentagem

O programa funciona em **loop**, permitindo repetir os cálculos quantas vezes o usuário quiser.

---

## 🎯 O que aprendi com esse projeto

✔️ Entrada de dados com `input()`  
✔️ Conversão de tipos (`int`, `float`)  
✔️ Estruturas de repetição com `while`  
✔️ Condicionais com `if/elif/else`  
✔️ Boas práticas de indentação e organização básica de código
